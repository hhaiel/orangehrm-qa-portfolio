# Evidence

Screenshots and recordings that support test results and defects.

**Naming:** `<TC or DEF ID>[-n].<ext>`
- `US-LV-0002-TC-003.png`: proof of a test result
- `DEF-004-1.png`, `DEF-004-2.png`: multiple shots for one defect
- `DEF-004.mp4`: short recording for tricky reproduction steps

**Tips**
- Capture the **whole browser window**, including the URL bar, so the page is clear.
- Highlight the problem (red box/arrow) in a copy. Keep the original unedited.
- Crop out personal info (your bookmarks, other tabs).
- Keep files small: PNG for screenshots, recordings under 30 s.
